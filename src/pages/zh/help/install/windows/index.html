RealtimeClipboard / Windows

在 Windows 上安装

Windows 是这个应用最值得装的平台：后台剪贴板捕获在这里没有任何附加条件， 也不弹权限请求。你在任何程序里复制，内容已经在你其他设备上了。

装上它

  1. 从发布页下载 RealtimeClipboard_<version>_x64_en-US.msi， 或者用下载页上的按钮，它会替你挑好文件。
  2. 运行它。没有管理员提示，也没有选项要选 —— 它按机器安装，不注册服务， 也不装驱动。
  3. 应用会开一个窗口，并在通知区域放一个图标。

同一个发布里还有一个 -setup.exe。它是同一份构建的 NSIS 安装包； 除非你的部署工具指定要那一个，否则请拿 .msi。

或者用包管理器

winget install AkshayNikhare.RealtimeClipboard

审核中。0.3.0 的清单已经 提交， 正在等微软的审核人员 —— 那些人不在这个项目里干活 —— 所以从发布到这条命令 能用之间，会有几天的空档。在它合并之前请用上面的 .msi；那就是 winget 会去取的同一个文件，它的 SHA256 也钉在那份清单里。

这里故意没有 scoop 那一行。一个 Scoop bucket 是一个得有人跟着 每次发布同步的仓库，而一条真正有人维护的 Windows 渠道，胜过两条各自漂走的。 反正上面那个 .msi 是同一份构建。

确认它装好了

这个应用是套在网站同一个页面外面的一个窗口，所以你看到的大部分就是网页版。 有两样东西能告诉你原生那一半在跑：

  • 一个托盘图标，在时钟旁边 —— 你可能得展开隐藏图标才看得到它。 双击它把窗口叫回来，或者右键打开菜单。退出就在那个菜单里， 这是有意的：一个会盯着你剪贴板的应用，必须有一个看得见的方式停下来。
  • 状态栏显示 T0 · watching the system clipboard，在右下角。 这个字符串就是桌面应用和一个浏览器标签页之间的全部差别。在浏览器里，同一个 位置最好也只显示 T3 · auto-capture，最差是 T1 · paste only。

它左边是连接状态，中继服务器一答复就会显示已连接。一直停在 正在连接…是网络问题，不是安装问题 —— 见下文。

你的第一次同步

  1. 在应用里记下顶部那个密钥，或者自己输一个。装好的应用生成十位密钥， 网站生成六位，两种在两边都能用。
  2. 在第二台设备上 —— 手机浏览器就行 —— 打开应用 并输入同一个密钥。
  3. 在 Windows 上复制点东西。不要切到 RealtimeClipboard：重点就是你不必切。 它会出现在另一台设备上。

如果它没出现，看一眼窗口顶部那个开关。在剪贴板上 —— 也就是默认值 —— 你复制的一切都会被分享。在应用内上，在你亲手粘贴进去之前，什么都不会 离开这台机器。应用内值得知道：应用运行期间，你每一次复制它都读得到， 包括你因为别的原因复制的密码。首次启动时弹出的那份引导就是这么说的，同一个 开关也在托盘菜单里，叫分享我复制的内容。

它不工作的时候

SmartScreen 对安装包发出警告

对一个新发布者来说这是意料之中的，而且总体上值得认真对待，而不是习惯性地点 过去。确认你是从官方发布页 拿到的文件，并且发布者对得上。这个警告会随着证书积累信誉而消失，而不是因为 构建本身有什么变化。

这是一台单位电脑

应用不需要管理员权限，不装驱动也不装服务。它只在 443 端口向一个主机名发起 出站连接，这正是 IT 部门愿意放行的形状。如果你们那边把它挡了，浏览器版什么 都不需要 —— 而如果连浏览器版也被挡了，那是一个策略决定，不是应该绕开的东西。

Windows 自带的“跨设备同步”是灰的

那是属于 Windows 的另一个功能，不属于这个应用，它不可用也有自己的一套原因。 那一页在这里。 它的任何情况都不影响 RealtimeClipboard，因为后者根本不用它。

卡在“正在连接…”

应用先开 WebSocket，被挡住时退回到 server-sent events 加 POST，所以一个禁止 协议升级的代理照样能用 —— 只是慢一些。如果两条都连不上，那就是中继服务器的 主机名被整个封了。你可以在设置 → 中继服务器里把应用指向你自己的中继 服务器；跑一个就是一个容器的事。

卸载

设置 → 应用 → 安装的应用 → RealtimeClipboard → 卸载，或者，如果它是那样装 进来的，用 winget uninstall AkshayNikhare.RealtimeClipboard。

之后没有什么需要清理。无论是应用还是中继服务器，都不会把任何剪贴板内容写到 磁盘上，所以卸载留下的只有你的设置和剪贴历史，而它们住在应用自己的浏览器 存储里，跟着它一起走。
