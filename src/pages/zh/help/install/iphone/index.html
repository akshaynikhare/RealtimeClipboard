在 iPhone 和 iPad 上安装

没有东西要下载，但有一个细节几乎绊倒了所有人：它必须是 Safari，而分享 菜单就是全部机制。不会有任何提示弹出来，你等多久都不会。

装上它

  1. 用 Safari 打开应用。
  2. 点工具栏里的分享 ↑。
  3. 往下翻，点添加到主屏幕，然后点添加。

iOS 上的 Chrome 和 Firefox 装不了网页应用。它们都是套了另一层外壳 的 Safari 引擎，而苹果并没有把主屏幕安装这件事开放给它们。如果你的分享 菜单里找不到添加到主屏幕，那说明的是你在用哪个浏览器 —— 不是某个 设置，页面这边也改不了。

为什么没有 App Store 版本

iOS 从来没有允许过任何应用在后台读取粘贴板，而且从 iOS 16 起， 只要有应用读了一次剪贴板，系统就弹一条横幅。这两件事都是苹果定的，对 平台上的每一个应用都成立，没有任何权限能把它们关掉。

所以一个原生的 RealtimeClipboard 应用，能在装好的网页应用之上再加的， 只有一个分享菜单按钮和一条商店条目，别的什么都没有。这不足以让我们请你 再去信任一个二进制文件。

你会看到的那条粘贴横幅 —— “RealtimeClipboard 已从……粘贴” —— 是 iOS 在 如实告诉你刚刚发生了什么。它出现，是因为你让应用去读了剪贴板，而任何 应用都无法把它压下去。

确认它装好了

  • 打开时没有 Safari 的工具栏 —— 全屏，在多任务切换里也是自己的 一个窗口。
  • 状态栏显示 T1 · paste only，这在 iOS 上是对的， 也是任何应用都碰不破的上限。
  • 没有网络也能打开，并且能看到你已有的历史记录。

第一次同步

  1. 在电脑上打开应用，记下那个短密钥。
  2. 在 iPhone 上输入同一个密钥。
  3. 在电脑上复制点东西。它会自己出现在手机上，你什么都不用做。
  4. 反过来：在手机上复制，打开 RealtimeClipboard，点一下编辑区，选 粘贴。iOS 会弹它那条横幅，这是正常的。

它不工作的时候

分享菜单里没有“添加到主屏幕”

要么你不在 Safari 里，要么这一项在列表里比你以为的更靠下 —— 把下面那 一段往上翻一翻。如果它被藏起来了，也可以从编辑操作里把它加回来。

没有弹出安装提示

本来就没有。iOS 对任何网页应用都不弹安装提示，从来不弹。如果你在等一条 提示，那你要等的其实就是分享菜单。

粘贴横幅一直在弹

那是 iOS 16 及以后在如实报告每一次剪贴板读取，对任何应用都一样。它没法 从应用内部关掉，而它出现恰恰说明这次读取成功了。

应用关着的时候收不到内容

你不看着它的时候，网页应用并没有在跑。它是在你打开的那一刻，把等着的 内容取回来；什么都不会丢。

卸载

长按图标把它删掉，它的存储也跟着一起走。Safari 自己那份站点数据可以在 设置 → Safari 浏览器 → 高级 → 网站数据里清掉。

其他所有平台：安装指南。 如果你真正要找的是 iPhone 和 Mac 之间的剪贴板同步， 那是另一个功能，说明在这里。 这一页有错或者过时了？ 提一个 issue。
