在 Linux 上安装

三种包格式，外加一条值得你在装任何东西之前先读一遍的限制：后台捕获 剪贴板在这里能不能用，是由你的合成器决定的，不是由这个应用决定的。

安装

从发布页取一个和你的发行版对得上的文件：

# Debian、Ubuntu 及其衍生版
sudo apt install ./RealtimeClipboard_<version>_amd64.deb

# Fedora、RHEL 及其衍生版
sudo dnf install ./RealtimeClipboard-<version>-1.x86_64.rpm

# 其他任何情况
chmod +x RealtimeClipboard_<version>_amd64.AppImage
./RealtimeClipboard_<version>_amd64.AppImage

AppImage 那个 chmod 少不了。用浏览器下载会清掉可执行位， 而由此产生的故障是：你双击之后文件管理器什么都不做 —— 看起来完全不像是 权限问题。

发行版底线：应用需要 webkit2gtk 4.1，大致相当于 Ubuntu 22.04 或 Fedora 36 及以上。发布版本是特意挑有它的最旧 runner 构建的，好把 glibc 的 要求压到最低。比这更老的系统，请用浏览器或者命令行客户端。

这里没有包管理器

没有 Flathub，没有 Snap，没有 AUR —— 这一页也不会写个命令假装有。这些各自 都是一个得有人跟着每次发布去更新的仓库，而一个悄悄停止更新的仓库比压根不 存在还糟：它递给别人一个旧版本，还告诉人家这是最新的。

上面那三个文件就是全部。每一个都是发布里的单个产物，谁都不需要仓库， AppImage 尤其什么都不用装 —— chmod +x，然后运行。

确认装好了

  • 托盘里出现一个图标，前提是你的桌面环境有托盘 —— GNOME 得装一个 扩展才能显示托盘图标，那是 GNOME 的决定，和这个应用无关。 右键点它打开菜单：在 Linux 上，托盘图标收不到属于自己的点击， 所以交互就只有这一种。Open 和 Quit 都在里面。关掉窗口不等于 退出 —— 有没有托盘图标，窗口都照常工作， Ctrl+Shift+V 也照常。
  • 右下角的状态栏才是真正的答案。在后台捕获可用的地方，它显示 T0 · watching the system clipboard。不可用的地方，它会直说， 而不是默默地什么都不做。

Wayland 那条限制，直说

会话后台捕获
X11，任意桌面可以
Wayland，KDE Plasma可以
Wayland，wlroots（Sway、Hyprland、river）可以
Wayland，GNOME不行 —— 改为在窗口获得焦点时捕获

在 X11 上，剪贴板一变，应用就会收到通知。在 Wayland 上，这完全取决于合成器： KDE 和基于 wlroots 的那些提供了对应的协议，GNOME 没有。在 GNOME Wayland 上，任何应用都无法监听剪贴板 —— 这不是这个应用缺了什么功能，别的工具 也一样没能解决。

在用不了的地方，应用退回到你切到它时再捕获，跟浏览器里的行为一模一样，并且 在状态栏里如实说明。如果后台捕获正是你要装它的理由，那么在 GNOME 上，答案 是改用 X11 会话。

第一次同步

  1. 记下应用顶部那个短密钥，或者自己输一个。
  2. 在第二台设备上打开应用，输入同一个密钥。
  3. 复制点什么。如果状态栏写的是 T0，你不需要切换窗口；如果不是， 点一下 RealtimeClipboard 窗口，内容会在它获得焦点的那一刻被取走。

窗口顶部那个开关默认在 Clipboard（剪贴板），也就是说你复制的每一样 东西都会被共享。它在运行期间会读取你的每一次复制，这件事值得你知道，而不是 稀里糊涂地继承下来 —— 应用在第一次启动时就会说明，而切到 App（应用） 之后，你不把内容粘贴进来，就没有东西离开这台机器。

不工作的时候

双击 AppImage 没有任何反应

给它 chmod +x —— 见上面。在终端里跑一次，你看到的就是真正的 报错，而不是一片安静。

安装时报缺少库

.deb 声明了 libwebkit2gtk-4.1-0、 libgtk-3-0 和 libayatana-appindicator3-1 | libappindicator3-1； 用 apt install ./file.deb 而不是 dpkg -i 来装， 依赖会帮你解决好。最后那个是画托盘图标的，写成一个“或”的关系是因为：较新的 Debian 里已经没有那个普通包，而一些较老的发行版里又没有 ayatana 那个 —— 你的发行版会有其中之一。至于老到连 webkit2gtk 4.1 都没有的发行版，那就是 上面说的那条底线，没有变通办法。

复制没有任何反应，状态栏也不显示 T0

那是 Wayland 那张表，不是故障。见上面。

一直停在 “Connecting…”

应用先试 WebSocket，在升级被挡住的地方回退到 server-sent events 加 POST。 如果两条都连不上，那就是中继服务器的域名被封了 —— 在 Settings → Relay 里把应用指向你自己的一台。 自己跑一个只要一个容器。

卸载

sudo apt remove realtimeclipboard      # or dnf remove
yay -R realtimeclipboard-bin

AppImage 就是一个文件：删掉就行。别的什么都不会留下 —— 剪贴板内容从来不会 写到磁盘上，你的设置和剪贴历史都存在应用自己的浏览器存储里。

准备好安装了：下载页。其他所有平台： 安装指南。这里有写错或者过时的地方？ 提一个 issue。
