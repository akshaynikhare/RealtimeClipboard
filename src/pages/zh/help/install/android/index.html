在 Android 和 ChromeOS 上安装

没有东西要下载。把这个网页应用加到主屏幕，它就有了自己的图标和窗口， 离线也能用 —— 这已经是一个应用商店里的 App 能有的全部能力，原因在 Android，不在我们。

装上它

  1. 用 Chrome 打开应用。
  2. 点菜单 ⋮，然后选 添加到主屏幕 —— 如果 Chrome 主动弹了安装提示，点它也一样。
  3. 确认。图标就落到主屏幕上了。

ChromeOS 是同一套流程，走同一个菜单。Firefox 和 Samsung Internet 也都 能做这件事，只是菜单项的叫法不同 —— Firefox 叫安装，Samsung Internet 是添加页面到 → 主屏幕。

为什么没有应用商店版本

从 Android 10 起，只有你当前正在用的应用、当前启用的输入法，或者一个 无障碍服务，才被允许读剪贴板。这条规则之所以存在，是因为一个能悄悄 读你剪贴板的应用，会把你复制过的每一个密码、每一个验证码都收走；它对 平台上的每一个应用一视同仁，没有例外。

所以一个原生的 RealtimeClipboard 应用，能多给你的只有一条分享菜单条目和 一条商店条目 —— 除此之外，没有一件事是装好的网页应用做不到的。它没法在 后台盯着你的剪贴板，因为没有任何东西能做到。真做出来，多半只是请你再 信任一个二进制文件，而换不来任何新能力。

手机上诚实的模型是这样：你把内容带给应用，应用把内容带给你。接收 是自动的 —— 你在电脑上复制的任何东西，等你打开它的时候就已经在那儿了。 发送则是一次粘贴或者一次分享，以后也一直会是。

确认它装好了

  • 打开时没有地址栏。这就是唯一靠得住的判断依据：主屏幕上的书签 快捷方式仍然会显示 Chrome 的界面，装好的网页应用不会。
  • 状态栏显示 T1 · paste only，这是对的，不是故障。 在 Android 上，这就是上限。
  • 没有网络也能打开，并且能看到你已有的历史记录。

第一次同步

  1. 在电脑上打开应用，记下那个短密钥。
  2. 在手机上输入同一个密钥。
  3. 在电脑上复制点东西。它会自己出现在手机上，你什么都不用做。
  4. 反过来：在手机上复制，打开 RealtimeClipboard，在编辑区长按 → 粘贴。或者在你正用着的那个应用里，直接走 Android 的分享菜单。

它不工作的时候

没有弹出安装提示

什么时候弹提示由 Chrome 自己决定，它并不总是弹。走菜单那条路任何时候都 管用，也是靠得住的那条 —— 别等提示。

它是在浏览器里打开的，不是自己的窗口

那你拿到的是一个书签快捷方式，不是装好的应用。把它删掉，从菜单里重新加 一次；你要的那一项叫添加到主屏幕，而当 Chrome 真的准备把它装起来 时，确认对话框里会显示应用图标。

应用关着的时候收不到内容

没错，而且绕不开：你不看着它的时候，网页应用并没有在跑，所以它是在你 打开的那一刻，去中继服务器上把等着的内容取回来。什么都不会丢 —— 会话 替你存着。

在手机上复制，发不出去

就是上面那条 Android 10 规则。粘贴进应用，或者分享给它。

卸载

长按图标，像卸载任何一个应用那样卸掉它，或者到 Chrome 的 设置 → 网站设置里删掉。除了它用来存你的设置和历史记录的那点浏览器 存储之外，设备上不会留下别的东西。

其他所有平台：安装指南。 如果你的剪贴板不同步，而原因和这个应用无关， 从这里开始。 这一页有错或者过时了？ 提一个 issue。
