联系

发邮件到 info@realtimeclipboard.com， 它会直接到维护这个项目的人手里。RealtimeClipboard 由一个人维护，所以 没有排队，也没有什么服务等级 —— 但同样没有人值夜班，下面写的时间是实话， 不是愿望。

写信之前：不要发送你的会话密钥

永远不要把共享密钥或会话 PIN 放进邮件、缺陷报告或截图里。密钥就是 全部的安全 —— 任何拿到它的人都能打开这个会话并读到里面的内容。如果你需要 演示一个问题，请另开一个用完即弃的会话来演示。应用的截图没问题，只要把密钥 面板裁掉，或者把密钥涂掉。

技术支持与一般问题

info@realtimeclipboard.com。大约 三个工作日内会有回复。

大多数"同步不了"的问题，有比一封邮件更快的答案，因为原因不多而且都很清楚 —— 没有授权就不肯读剪贴板的浏览器、两台设备用了不同的密钥，或者某个扩展挡住了 连接。剪贴板同步排查指南 会按顺序把它们过一遍，帮助中心则讲了各个平台上怎么 安装。先试这两处，通常一分钟就完事了。

缺陷与功能建议

在 GitHub 上提一个 issue。任何能复现的问题，这都比邮件更合适：它是公开的，所以下 一个碰到同样问题的人能找到答案，而修复落地时也会链接在那里。

一份有用的报告会说明两端各是什么浏览器和操作系统、你期待发生什么、实际发生了 什么，以及浏览器控制台里有什么。项目里的一切都是开源的，所以如果你更愿意直接 发一个 pull request 而不是一段描述，那也一样可以。

安全问题披露

安全问题有自己的通道，不应该发到公开的 issue 里。 提交 一份私密安全通报 —— 它只对你和维护者可见 —— 或者，如果这个表单对你不 可用，就发邮件到 info@realtimeclipboard.com。

大约一周内会收到确认。经核实的报告会在安全通报和更新日志里署名致谢，除非你 不希望这样。这里没有漏洞赏金，也没有报酬 —— 它是一个由一个人维护的免费工具， 假装不是这样只会浪费你的时间。完整的政策，包括哪些已知的取舍是刻意的设计而 不是缺陷，都写在 SECURITY.md 里。

隐私相关请求

请发到 info@realtimeclipboard.com。 请先有个心理准备：通常的答复是没有东西可以交出 —— 没有账号，没有留存的邮箱， 服务器上也没有任何会话的记录，所以一个服务通常会掌握的关于你的材料，在这里 根本不存在。至于 Google 掌握的广告和分析数据，隐私政策 里的链接能到达的地方，比向本站提出任何请求都更远。

媒体、广告与商务合作

info@realtimeclipboard.com，请在 主题里写上"媒体"或"商务"。RealtimeClipboard 由 CadNative 发布。标志和图标资源 都在仓库里， 可以用来指代这个项目。

为什么没有联系表单

表单总得把内容提交到某个地方，而那意味着一台会保存消息的服务器。这个项目里 唯一的服务器是中继服务器，它被造成无法保存任何东西，而且保持这样更有用。一个 邮箱地址做的是同样的事，同时让架构保持诚实。
