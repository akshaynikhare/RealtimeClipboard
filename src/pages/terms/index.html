What the service is

A relay that forwards encrypted messages between devices holding the same session key, and a signalling path that lets those devices connect directly to send files. It is not storage, not a backup, and not a record. Messages exist in memory for the moment it takes to forward them and are never written to disk.

Your session key is your responsibility

The session key is a bearer credential: anyone who has it can join the session and read what is in it. That is a consequence of a short key with no account, not an oversight, and it means two things are on you.

Do not share a key with anyone you do not intend to share the clipboard with, and be careful where a share link is posted — a link contains the key. If a session needs more protection, lock it with a PIN.

A lost key cannot be recovered. There is no reset, because there is no account and nothing on the server that knows the session was yours. This is the same property that makes the service private, and it cannot be relaxed for one person without being relaxed for everyone.
