Baixar o RealtimeClipboard

Você não precisa de nada disto. O RealtimeClipboard roda numa aba do navegador em todo dispositivo que você tem, e isso é o produto inteiro. O aplicativo para desktop acrescenta uma única coisa que o navegador não consegue fazer de jeito nenhum: ele percebe o que você copia enquanto você está trabalhando em outro lugar.

Um clique · sem terminal

Instale

Baixe, abra, pronto. Escolha a máquina em que você está sentado.

Desktop — Windows, macOS, Linux

O aplicativo para desktop é uma janela em volta da mesma página, mais um pequeno auxiliar nativo que observa a área de transferência do sistema. Esse auxiliar é a razão de ele existir: copie em qualquer programa e o texto já está nos seus outros dispositivos antes de você trocar para eles.

Ele lê tudo o que você copia enquanto está em execução. É isso que você está instalando. Ele nunca grava nada em disco, e o conteúdo é criptografado antes de sair da máquina — mas, se você prefere que ele envie só o que você escolher, mude para Aplicativo nas configurações.

Quais compositores, e por quê →

Estas builds ainda não são assinadas, e o seu computador vai dizer isso. O Windows mostra “O Windows protegeu o seu PC” — escolha Mais informações → Executar assim mesmo. O macOS recusa a primeira abertura; vá em Ajustes do Sistema → Privacidade e Segurança e clique em Abrir Mesmo Assim. Nenhum dos dois quer dizer que o arquivo está corrompido: um certificado custa dinheiro por ano e este projeto não comprou nenhum, então nada responde pelo binário além do checksum na página da release e do fato de que você pode ler cada linha que entrou nele.

Android, iPhone e iPad

Não há aplicativo para instalar, e isso é uma decisão deliberada, não uma lacuna. Nenhuma das duas plataformas deixa aplicativo nenhum ler a área de transferência em segundo plano — o Android restringiu isso na versão 10, e o iOS nunca permitiu. Um aplicativo nativo poderia, então, oferecer um botão no menu de compartilhamento e uma página na loja, e nada além disso que a página em que você está lendo já não faça.

Então adicione à tela de início. Ele ganha ícone e janela próprios, e funciona offline.

Linha de comando · avançado

Instale pelo terminal

As mesmas builds, por um gerenciador de pacotes em que você já confia para atualizá-las — e, para máquinas sem desktop nenhum, um cliente que é só cano e nenhuma janela.

Gerenciadores de pacotes

Dois, e só depois que forem reais. Cada um é um manifesto que o tools/release/manifest.mjs gera a partir da release, e que ainda precisa ser revisado e mesclado por outra pessoa — então o comando funciona quando a etiqueta ao lado dele disser que sim, e não antes.

Windows — winget

em revisão 
winget install AkshayNikhare.RealtimeClipboard

O manifesto da 0.3.0 foi enviado e está esperando os revisores da Microsoft, o que leva dias e não minutos. Este comando começa a funcionar no instante em que ele for mesclado, e não antes. Notas de pacote do Windows

macOS — Homebrew

brew install --cask akshaynikhare/tap/realtimeclipboard

O cask instala a mesma build universal que o botão acima entrega, e atualiza com brew upgrade. Ele também remove a marca de quarentena, então você pula a dança do Gatekeeper que o download manual exige. Notas de pacote do macOS

Linux — nenhum

Nenhum pacote no Flathub, no Snap ou no AUR, e nenhum comando aqui fingindo o contrário. Pegue o .deb, o .rpm ou o AppImage acima; cada um é um arquivo só e nenhum deles precisa de repositório. Notas de pacote do Linux

Dentro do seu editor

Uma área de transferência que segue você entre máquinas sem sair da janela em que você já está. Ela continua sincronizando com o editor em segundo plano, que é a única coisa que o aplicativo web não consegue fazer.

VS Code

code --install-extension cadnative.realtimeclipboard

Ou procure por RealtimeClipboard na aba de extensões. Precisa do VS Code 1.100 ou mais recente. Ver no Marketplace

Cursor, Windsurf, VSCodium

ext install cadnative.realtimeclipboard

Nenhum dos forks do VS Code pode usar o marketplace da Microsoft, então a mesma build é publicada no Open VSX, que é onde todos eles procuram. Gitpod e code-server também. Ver no Open VSX

No seu navegador

Um popup e dois atalhos de teclado, para enviar o que você copiou sem abrir o aplicativo. Não está em loja nenhuma: a build acompanha cada release como um zip, e o Chrome a carrega de uma pasta.

Chrome, Edge, Brave — carregar sem compactação

# 1. pegue realtimeclipboard-browser-<version>.zip da release acima
# 2. descompacte num lugar que você vai manter
# 3. chrome://extensions -> Modo do desenvolvedor -> Carregar sem compactação -> escolha a pasta

Guarde a pasta: o navegador a lê a cada inicialização, então a pasta de downloads que você esvazia é o lugar errado. Assim não há atualização automática, e o Chrome vai perguntar de vez em quando se você queria mesmo manter uma extensão em modo de desenvolvedor. Não existe instalador de um clique porque nenhuma release traz um .crx — e, no Windows e no macOS, o Chrome recusaria um vindo de fora da Web Store dele de qualquer jeito. Última release

Só Chromium — Chrome, Edge, Brave, Opera, Arc. Firefox não: a ponte com a área de transferência precisa de uma API que o Firefox não implementa. E ela não sincroniza em segundo plano em navegador nenhum, que é justamente para o que servem o aplicativo para desktop e a extensão do editor.

Servidores, SSH e scripts

Um cliente de linha de comando, para as máquinas que não têm área de transferência nenhuma. Ele fala o mesmo protocolo e a mesma criptografia que o navegador — importa exatamente os mesmos arquivos — então um trecho enviado de um servidor aparece no seu notebook como qualquer outro. 

npx realtimeclipboard D75LV

Para que ele serve

# mande algo pelo cano
echo "deploy key" | npx realtimeclipboard send D75LV

# pegue o próximo trecho e pare
npx realtimeclipboard watch D75LV --once > token.txt

# de uma máquina em que você entrou por ssh
ssh build-01 'cat /var/log/deploy.log' | npx realtimeclipboard send D75LV

Precisa do Node 22 ou mais recente, e não instala nada: o npx busca sob demanda. O guia da linha de comando →

Rode o seu próprio retransmissor

O retransmissor leva trechos criptografados entre dispositivos. Ele nunca vê nada além de um hash de sala e texto cifrado, e não guarda nada — mas você não precisa acreditar nisso, porque pode rodá-lo você mesmo. É um arquivo Python só, sem banco de dados. 

docker run -p 8000:8000 ghcr.io/akshaynikhare/realtimeclipboard-relay

Ou a partir do código

pip install -r backend/requirements.txt
python -m uvicorn main:app --app-dir backend --port 8000

Para TLS e um domínio de verdade use deploy/docker-compose.yml, e há um chart do Helm ao lado. Depois aponte o aplicativo para o seu retransmissor em Configurações → Retransmissor. O guia de auto-hospedagem →
